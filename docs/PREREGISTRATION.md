## Why this document exists

The probe asks whether prompting alone already produces acceptable Kuwaiti. If it does, roughly 35 hours
of fine-tuning work is unnecessary. That makes it a decision with a strong pull toward one answer —
having invested in a fine-tuning plan, the natural instinct is to find the baseline wanting.

Thresholds written after seeing outputs are not thresholds. This file exists so the decision rule is
fixed while nobody knows what the outputs look like.

---

## What will be run

**Model:** `humain-ai/ALLaM-7B-Instruct-preview`, 4-bit NF4, **no training of any kind.**

**Three arms**, all on the same 40 held-out prompts:

| Arm | Configuration |
|---|---|
| A1 | Zero-shot, no system prompt |
| A2 | Kuwaiti system prompt, no examples |
| A3 | Kuwaiti system prompt + **5 verbatim real examples** written by the author (P0.2), best-of-8 @ temp 0.8 |

**Decoding is pinned and recorded:** `temperature=0.8`, `top_p=0.9`, `seed=42`, `max_new_tokens=120`.
Best-of-8 selection for A3 uses the **unfitted heuristic only** (anti-marker veto + length prior) —
no classifier, since Gate B has not yet returned.

## What will be judged

A single blind rating set of **60 items**, shuffled, unlabelled, in one session:

| Type | n | Purpose |
|---|---|---|
| **A3 model outputs** | 30 | the thing being measured |
| **Real human Kuwaiti** | 15 | rater-validity anchors + the ceiling |
| **Marker-stuffed** | 8 | caricature detection check |
| **MSA / other-Gulf** | 7 | floor anchors |

Real anchors are drawn from **QADI**, not the author's own writing — the author would recognise their
own text and the anchor would be void.

**Question asked, verbatim:** *"Was this written by a Kuwaiti person, or generated by a machine?"*
Binary. Neutral framing — the rater is **not** told what is being tested, and specifically not told to
"rate how Kuwaiti this is."

---

## Rater validity — checked first

Let **H** = % of the 15 real human anchors correctly judged human.

| H | Consequence |
|---|---|
| **≥ 0.80** | Session valid, proceed to the decision rule |
| **< 0.80** | **Session void.** The rater cannot reliably identify real Kuwaiti under these conditions; no model number from this session means anything. Re-run with a different item pool |

Also recorded, and reported regardless of outcome:

- **C** = % of the 8 marker-stuffed items judged *human*.
  If **C ≥ 0.50**, the rater cannot detect caricature. This does not void the session, but it is a
  finding in its own right and it invalidates any later claim resting on naturalness judgement.
- **F** = % of the 7 MSA/other-Gulf floor anchors judged *human*. Expected low; a high F means the task
  isn't discriminating.

---

## The decision rule

Let **M** = % of the 30 A3 outputs judged human.
The comparison is **M against H**, not against an absolute number — H is the achievable ceiling for this
rater on this task, and an absolute target would be meaningless without it.

| Condition | Verdict | Action |
|---|---|---|
| **M ≥ 0.60 × H** | **Prompting suffices** | **Stop. Ship the prompted demo.** No fine-tune. Phase 1 and 2 are cancelled |
| **0.30 × H ≤ M < 0.60 × H** | **Partial** | Fine-tune, but scoped to the *specific* failure modes listed below — not a general-purpose run |
| **M < 0.30 × H** | **Prompting is insufficient** | Proceed to Phase 1 as planned, with justification on record |

Worked example: if H = 0.87 (13/15), then the "ship it" line is **M ≥ 0.52** and the "full fine-tune"
line is **M < 0.26**.

## Qualitative output — required regardless of branch

Before looking at any number, the author writes down **the three most specific things wrong** with the
A3 outputs. Not "it doesn't sound Kuwaiti" — concrete: *"uses MSA negation," "word order is written not
spoken," "never uses the ـچ suffix," "too long."*

This list is what a scoped fine-tune would target, and writing it before seeing the score keeps it
honest.

## Commitments

1. **Thresholds do not move after data is seen.** If the result is inconvenient, it is still the result.
2. **A "prompting suffices" outcome is a success, not a failure.** AL-QASIDA ([arXiv 2412.04193](https://arxiv.org/abs/2412.04193))
   finds these models are *reluctant* to emit dialect rather than unable, and that few-shot mitigates it.
   Prompting winning is the **modal predicted outcome**, not a long shot.
3. **Raw per-item judgements are saved** to `eval/raw/probe_ratings.jsonl` — item id, type, verdict,
   order seed. Aggregates alone are not sufficient evidence.
4. **The gold set (D0) is not touched.** Probe prompts come from P0.2's seed batch and QADI.
5. **If the session is void (H < 0.80), no result is reported** — not even informally.

## Open — set these before freezing

- [ ] Are the 0.60 / 0.30 multipliers right? They are a judgement call, not derived. Lower them and you
      bias toward shipping the prompt; raise them and you bias toward fine-tuning
- [ ] Is n=30 model outputs enough? At n=30 the 95% CI on M is roughly ±18pp — wide. n=60 halves the
      cost of a wrong call but doubles the rating time (~40 min instead of ~20)
- [ ] Second rater for the probe, or author only? Author-only is acceptable *here* because the
      discrimination task is self-validating via H, unlike a naturalness Likert
