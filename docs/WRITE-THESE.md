# Kuwaiti Writing Worksheet — Batch 1

**120 situations. You write what a Kuwaiti would actually type.**

This is the highest-value data in the project. Everything else is either synthetic (bounded by my
approximation of Kuwaiti) or scraped (noisy, auto-labelled, licence-ambiguous). This is the only source
that's genuinely, unambiguously real — which makes it the only thing that can honestly measure whether
the fine-tune worked.

---

## How to fill this in

Each item gives you a **situation in English**. You write the Arabic. **Do not translate my English** —
read the situation, picture it, and write what you'd actually thumb into WhatsApp or post as a reply.
If my situation feels unnatural for Kuwait, **change it** and note what you changed.

```
**KW-001** · greetings · question
> Situation text here.
- **User:**
- **Reply:**
```

Write directly after `**User:**` and `**Reply:**`. Don't change the headers or the ID — a script parses
these later.

### Rules

| | |
|---|---|
| **Script** | Arabic only. Use **چ** and **گ** wherever you'd naturally use them (چذي، گلت، عليچ، چم). |
| **No Arabizi** | Nothing like `shlonik` or `3ndi` or `7abibi`. Arabic script throughout. |
| **Register** | Young, casual, social-media Kuwaiti. How you'd text a friend — not how you'd write an email. |
| **Length** | Short. Real Kuwaiti posts run **8–21 words**, median 13. If a reply hits 40+ words, it's probably too formal. |
| **Emoji** | Use them if natural, max 2. Real data has them. |
| **Messy is good** | Repeated letters (هههههه، زييين), dropped hamzas, run-on phrasing — all fine. Don't clean it up. Naturalness beats correctness. |
| **Vary it** | Don't let every reply start the same way. Mix warm, blunt, sarcastic, rushed, bored. |

### If you're short on time
Items marked **○** are lower priority — skip them and come back. Items marked **★** are the ones I most
want; do those first.

### Important: don't write "for the test"
I'm going to randomly assign these to the gold test set vs. training seeds **after** you write them, and
I won't tell you which is which. That's deliberate — if you knew which were being graded you'd
unconsciously write them more carefully, and the test set would stop reflecting your natural output.
Just write everything the same way.
